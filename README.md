# SpendWise Dashboard

## Project Description
SpendWise is a responsive financial dashboard designed to help users visualize and organize their expenses. It uses HTML and CSS to create a clean, modern dashboard interface.

## Features
- Sidebar navigation menu.
- Responsive dashboard header.
- Six expense category cards: Food, Transport, Rent, Entertainment, Savings, and Utilities.
- CSS Grid and Flexbox layouts.
- CSS custom properties for consistent styling.
- Hover and keyboard focus animations.
- Responsive design for mobile and desktop.
- Dark theme support.

## Technologies Used
- HTML5
- CSS3
- CSS Grid
- Flexbox
- Media Queries

## Note
This project currently displays static financial information. JavaScript functionality will be added in future development.
